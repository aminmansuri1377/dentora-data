# Dentigo Crawler — نسخه ۳٫۱

**اگر ورود Google در مرورگر اسکرپر رد می‌شود، ابتدا START-HERE.fa.md را بخوان؛ نسخه ۳٫۱ ورود با فایل نشست دنتیگو را پشتیبانی می‌کند.**

ابزار مستقل برای استخراج فارسی از حساب مجاز خودت؛ هیچ API هوش مصنوعی ندارد.
متن، ساختار پاراگراف/فهرست/جدول، تصویر در جای اصلی، سؤال، گزینه، بازخورد و
کلید اعلام‌شده منبع را ذخیره می‌کند. ترجمه، تغییر پروژه Dentora یا ورود اطلاعات
به Supabase انجام نمی‌دهد.

## شروع سریع در Windows

این ZIP را در پوشه جدا از پروژه Dentora باز کن. Node.js نسخه 22 یا جدیدتر و
Google Chrome نصب باشد. در همان پوشه PowerShell باز کن:

```powershell
npm install
npm run crawl -- --lesson https://app.dentigoapp.com/fa/lesson/1636
```

**نیازی به `npx playwright install chromium` نیست.** پیش‌فرض، Chrome نصب‌شده
کامپیوتر است؛ بنابراین دانلود Chromium که قبلاً برایت 403 می‌داد لازم نیست.
اگر Chrome نداری ولی Edge نصب است:

```powershell
npm run crawl -- --channel msedge --lesson https://app.dentigoapp.com/fa/lesson/1636
```

مرورگر مستقل باز می‌شود؛ خودت وارد حساب شو، تخصص ترمیمی را انتخاب کن و در
ترمینال Enter بزن. ابزار از آنجا خودکار پیش می‌رود. رمزت را به هیچ فایل
کانفیگ یا چت نده. نشست مرورگر در `.session` نگه داشته می‌شود؛ این پوشه خصوصی
را همراه خروجی برای کسی نفرست. Chrome معمولی خودت را لازم نیست با remote
 debugging باز کنی. یک profile اختصاصی استفاده می‌شود.

ورود جداگانه (اختیاری؛ برای اجرای بعدی نشست می‌ماند):

```powershell
npm run login
```

اگر ورود ذخیره شده و تخصص درست انتخاب شده است، برای اجرای بدون مکث از
`--no-prompt` استفاده کن. ورود منقضی شود، ابزار خطا ثبت می‌کند؛ آن را دور نمی‌زند.

## پس از تطبیق یک درس، پنج درس آزمایشی

```powershell
npm run crawl -- --max-lessons 5
```

تخصص انتخاب‌شده را می‌خواند. این عدد سقف درس‌هایی است که در این اجرا پردازش
می‌شوند؛ وعده استخراج پنج درس کامل نیست. درس قفل‌شده یا ناقص در گزارش می‌آید.

تمام درس‌های تخصص انتخاب‌شده:

```powershell
npm run crawl
```

پیمایش تخصص‌ها با دکمه «تخصص بعدی» سایت:

```powershell
npm run crawl -- --all-specialties
```

این گزینه انتخاب تخصص حساب را تغییر می‌دهد. صف هر تخصص دوباره از صفحه home
خوانده می‌شود تا درس‌هایی که با اتمام درس قبلی باز می‌شوند وارد صف شوند.
هیچ URL مربوط به درس قفل‌شده از روی شناسه حدس زده نمی‌شود. محدودیت Pro، قلب،
پیش‌نیاز یا دسترسی سایت منبع دور زده نمی‌شود. اشتراک Pro لزوماً پیش‌نیاز ترتیب
درس‌ها را حذف نمی‌کند. برای باز شدن خودکار مراحل بعدی باید سایت تکمیل درس را
بپذیرد. اگر حساب قفل یا محدود شد، آن مورد ناقص/قفل ثبت می‌شود.

## پاسخ دادن خودکار و محدودیت انواع سؤال

پیش‌فرض `--answer-mode first` است: در سؤال تک‌گزینه‌ای ناشناخته، اولین گزینه را
ثبت می‌کند تا بازخورد واقعی دیده شود. گزینه انتخاب‌شده «پاسخ صحیح» فرض نمی‌شود.
کلید صحیح فقط با بازخورد غیرخالی و دقیقاً یک گزینه دارای کلاس correct ثبت
می‌شود. هنگام تکرار سؤال، کلید قبلی با **محتوای گزینه** تطبیق داده می‌شود، نه
شماره‌ای که با جابه‌جایی گزینه‌ها عوض می‌شود.

ثبت پاسخ روی حساب منبع واقعی است و ممکن است قلب، XP، امتیاز و پیشرفت را تغییر
دهد. راهنماهای هزینه‌دار خریداری نمی‌شوند؛ این نسخه متن hintهای پولی را جمع
نمی‌کند. تبلیغ، آواتار و مسکات تزئینی خارج از بدنه درس، تصویر آموزشی حساب
نمی‌شود. محتوای اصلی راهنمای فصل هم فعلاً جزو خروجی این نسخه نیست.

قالب تک‌گزینه‌ای مشاهده‌شده خودکار پشتیبانی می‌شود. برای قالب چندپاسخی، متن
آزاد یا drag/drop، ابزار در حالت خودکار متوقف می‌شود و داده ذخیره‌شده را نگه
می‌دارد. برای ثبت محتوا و بازخورد قابل‌مشاهده با پاسخ‌دادن خودت:

```powershell
npm run crawl -- --answer-mode manual --lesson https://app.dentigoapp.com/fa/lesson/1636
```

در مرورگر پاسخ بده و «بررسی» را بزن؛ پس از ظاهر شدن بازخورد، در ترمینال Enter
بزن؛ «ادامه» را ابزار می‌زند. در قالب‌های خارج از تک‌گزینه‌ای، پاسخ صحیح ممکن
است قابل اثبات نباشد و با وضعیت unverified / needs-review ذخیره می‌شود؛ هرگز
کلید حدسی به‌جای کلید واقعی تولید نمی‌شود. پشتیبانی خودکار از تمام انواع سؤال
و تمام تخصص‌ها هنوز روی حساب واقعی آزموده نشده است.

## خروجی

```text
output/
  run-report.json
  specialty-HASH/
    catalog.json
    coverage.json
    assets/
      HASH.png
    lessons/
      1636/
        lesson.json
        preview.html
        diagnostic.json       (فقط هنگام خطا)
        history/              (نسخه‌های قبل از اجرای دوباره)
```

- `lesson.json`: منبع اصلی داده، schemaVersion=3. `steps` ترتیب واقعی درسنامه و
  سؤال را نگه می‌دارد؛ `visits` تکرار سؤال‌ها را جدا ثبت می‌کند.
- `content` درخت مرتب و بدون کد اجرایی است؛ img داخل همان پاراگراف/شکل اصلی
  باقی می‌ماند. `assetPath` مسیر نسبی عکس ذخیره‌شده است و caption هم حفظ می‌شود.
- `options` ترتیب نمایشی گزینه‌ها را دارد؛ پاسخ و توضیح در `answer` است.
- `preview.html`: نمایش آفلاین برای کنترل متن/تصویر/سؤال/بازخورد؛ بازسازی پیکسلی
  UI سایت نیست. فایل را با مرورگر باز کن و پوشه assets را همراهش نگه دار.
- `coverage.json`: ردیف تمام درس‌ها، ترتیب بخش، وضعیت، دلیل قفل و مشکلات استخراج.
- JSON با ساختار raw فارسی نگه داشته شده؛ مستقیم با importer قدیمی Dentora
  وارد نکن. در مرحله ترجمه/ورود، تبدیل کنترل‌شده به schema پروژه لازم است.

برای ارسال به من، **پوشه output را ZIP کن**. پوشه `.session`، `node_modules`
و هر فایل رمز/کوکی را داخل ZIP نگذار.

## وضعیت دقیق کامل‌بودن

- `captured`: صفحه پایان دیده شد، تمام قدم‌های مشاهده‌شده و کلید سؤال‌های
  تک‌گزینه‌ای و تصاویرشان ثبت شدند؛ تعداد واقعی مورد انتظار مستقل تأیید نشده.
- `validated`: علاوه بر موارد بالا، تعداد صفحات و سؤال‌ها با تعداد مستقلاً
  واردشده در تنظیمات تطبیق دارد.
- `needs-review`: پایان دیده شده ولی تصویر، پاسخ یا شمارش ایراد دارد.
- `incomplete`: توقف، اتصال ناموفق، قالب ناشناخته یا پایانِ مشاهده‌نشده.
- `locked` / `pending`: در گزارش تخصص؛ استخراج نشده است.

هیچ اسکرپری صرفاً با دیدن دکمه پایان نمی‌تواند نبودن هر صفحه جاافتاده را
صددرصد اثبات کند. اگر تعداد واقعی یک درس را می‌دانی، در crawler.config.json
بگذار؛ درس 1636 از قبل با دو درسنامه و پنج سؤال در کانفیگ ثبت شده است:

```json
"expectedByLesson": {
  "1636": { "pages": 2, "questions": 5 }
}
```

اگر تعداد بخش اعلام‌شده در صفحه قابل تشخیص باشد، با تعداد بخش‌های جمع‌آوری‌شده هم مقایسه می‌شود و اختلاف به‌عنوان نقص فهرست گزارش می‌شود.

بازبینی تعدادها مستقل از صحت علمی است؛ کلید و توضیح منبع ممکن است ایراد علمی
داشته باشند. این برنامه هیچ ترجمه یا بازبینی علمی انجام نمی‌دهد.

بررسی دوباره خروجی‌ها:

```powershell
npm run validate
```

کد خروج 0 = بررسی بدون ایراد کشف‌شده؛ 2 = خروجی ناقص/نیازمند بررسی؛ 1 = خطای
اجرایی. وضعیت captured در validate هم به معنی تأیید تعدادهای نامعلوم نیست.

## ادامه پس از قطع و استخراج دوباره

همان دستور را دوباره اجرا کن. درس captured/validated رد می‌شود؛ درس ناقص از
**ابتدای همان درس** دوباره پیمایش می‌شود؛ نسخه قبلی در history می‌ماند و کلید
پاسخ‌های قبلاً دیده‌شده برای عبور از تکرار استفاده می‌شود. از بازیابی مخفی
وضعیت سرور به وسط سؤال استفاده نمی‌شود. قدم‌های اجرای قبلی به اجرای جدید
بی‌قاعده اضافه نمی‌شوند.

استخراج دوباره درس‌های پایان‌یافته:

```powershell
npm run crawl -- --force
```

## تصاویر و تغییر قالب سایت

پیش‌فرض تصاویر هم‌دامنه دانلود می‌شوند. لینک دامنه دیگر با خطا ثبت می‌شود؛
دامنه CDN آموزشی واقعی را دقیقاً در `allowAssetHosts` کانفیگ اضافه کن تا اجازه
دانلود داشته باشد. برای امنیت ریدایرکت تصویر خودکار دنبال نمی‌شود. قالب‌های
PNG/JPEG/WebP/GIF/SVG/AVIF پشتیبانی می‌شوند؛ داده base64 تصویر هم قابل ذخیره است.
SVG درختی داخل درس نگه داشته می‌شود؛ تصاویر HTML img با caption و ترتیب حفظ
می‌شوند. ویدیو، canvas، CSS background و رسانه تعاملی تخصصی نیازمند adapter
جدا هستند؛ این نسخه ادعای استخراج تمام رسانه‌های ممکن را ندارد.

Selectors در config قابل تنظیم‌اند. اگر قالب یا نوع سؤال عوض شد، خروجی ناقص
ثبت می‌شود؛ برنامه از روی هر پاسخ JSON شبکه یک قدم خیالی نمی‌سازد. از DOM
پس از به‌روز شدن صفحه استفاده می‌کند، چون پاسخ Livewire مربوط به دکمه ذخیره
لزوماً ربطی به قدم درس ندارد.

## آزمایش‌ها و دامنه اعتبارسنجی

```powershell
npm test
npm run typecheck
npm run test:browser
```

`npm test`: تست خودکار DOM شبیه‌سازی‌شده با ۱۰ صفحه درسنامه، ۵ سؤال، بازخورد
با تأخیر، تکرار سؤال و گزینه‌های جابه‌جا، راهنمای اولیه، تصاویر درون متن،
تصویر ناموفق، checkpoint و بازخوانی فهرست. این تست Chrome واقعی نیست.

`npm run test:browser`: همان جریان طولانی روی یک سایت محلی آزمایشی در Chrome
واقعی؛ هیچ حساب منبعی را استفاده نمی‌کند. Chrome باید نصب باشد. برای انتخاب
فایل اجرایی مرورگر تست می‌توان CRAWLER_TEST_BROWSER را تنظیم کرد.

در محیط ساخت این بسته، اجرای Chromium به‌دلیل محدودیت socket سیستم ممکن نبود؛
بنابراین تست مرورگر واقعی در این محیط تأیید نشده است. ورود و DOM واقعی درس
1636 (دو صفحه، سؤال، تأخیر بازخورد و کلاس‌های correct/wrong) و فهرست home در
مرورگر زنده بررسی شدند؛ اجرای انتهابه‌انتهای همین ابزار روی کل حساب انجام
نشده. ابتدا یک درس را با منبع تطبیق بده، سپس اجرای پنج‌درسی و بعد تخصص کامل.
